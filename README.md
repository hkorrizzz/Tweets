**Анализ твиттер трендов, 2024, C#, Windows Forms, .NET**  


Приложение работает с набором данных, содержащих твиты с привязкой к географическим координатам, датой и временем публикации, а также текстом сообщения. Входные данные включают файлы с твитами по различным темам (например, "cali", "football", "movie"), словарь тональности слов (sentiments.csv) с числовыми весами положительных и отрицательных эмоций, и JSON-файл с геометрическими границами штатов США, где каждый штат представлен в виде набора полигонов. 

Моя задача заключалась в том, чтобы извлечь слова из текста каждого твита, вычислить его среднюю тональность на основе слов из словаря, определить штат по географическим координатам, сгруппировать твиты по штатам и рассчитать среднюю тональность для каждого региона.

Результатом работы программы стала визуализация карты США, где каждый штат окрашен в цвет, соответствующий агрегированной тональности твитов, относящихся к этому штату. Ниже представлены скриншоты работы приложения.

**Структура проекта (ЗА ЧТО ОТВЕЧАЮТ КЛАССЫ)**
- Tweet – модель твита (текст, координаты, сентимент)
- TweetsExtraction – парсинг и очистка твитов
- TweetsAnalyzer – анализ тональности
- StatesAnalyzer – привязка к штатам
- StateVisualizer – отрисовка карты
- SentimentColorCalculator – вычисление цвета
